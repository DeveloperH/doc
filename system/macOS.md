# macOS

## 快捷键

### 显示隐藏文件

打开访达，进入你要查看的文件夹，然后按：

**`Command + Shift + .`**（也就是 `⌘ + ⇧ + .`，句号键）

按一次，隐藏文件会以半透明灰显的方式出现；再按一次，就会重新隐藏。这个开关是全局的，在文件选择窗口里也有效。



### 截屏

macOS 自带截屏功能，快捷键很直接，不需要装任何软件。



#### 快速截屏（全屏）

**`Command + Shift + 3`**

按下后立刻截取整个屏幕，图片会自动保存到**桌面**。如果同时按 `Control`（即 `Command + Shift + Control + 3`），截图会直接复制到剪贴板，不存文件。



#### 选中区域截图

**`Command + Shift + 4`**

按下后鼠标会变成十字准星，然后：

- **拖拽**：按住鼠标左键拖出一个矩形区域，松开即截图
- **按住 `Option` 拖拽**：以起点为中心向四周扩展，方便截取对称区域
- **按住 `Shift` 拖拽**：锁定一边，只调整另一边，方便截取精确的宽或高

截图同样保存到桌面。如果按住 `Control`（`Command + Shift + Control + 4`），则直接复制到剪贴板。



#### 截取单个窗口

**`Command + Shift + 4`，然后按空格键**

鼠标会变成相机图标，移到目标窗口上点击，就能干净地截取整个窗口，**自带阴影效果**。如果按住 `Option` 点击，阴影会消失，只截窗口本身。



#### 截图后的小技巧

截图完成后，屏幕右下角会出现一个缩略图。**别等它消失**：

- **点击它**：进入标记界面，可以画圈、加文字、裁剪，然后直接保存或分享
- **拖拽它**：可以直接拖到微信、邮件等应用里发送
- **右键它**：可以选择保存位置或拷贝

如果错过了缩略图，图片已经在桌面上了，直接去桌面找就行。



#### 进阶：用截屏工具栏

**`Command + Shift + 5`**

会调出一个工具栏，集成了以上所有功能，还能：

- 录制整个屏幕或选定区域
- 选择保存位置（桌面、文稿、剪贴板、邮件等）
- 设置定时器（5 秒或 10 秒后自动截图）

日常用前两个快捷键足够了，`Command + Shift + 5` 适合需要录屏或改保存位置时用。
